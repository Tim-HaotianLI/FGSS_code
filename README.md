## Introduction
This repository is for the code of FGSS model.
1. folder `vgms_code` contains all kinds of vgms testing code
2. folder `explainable` contains codes of three different kinds of explainable methods.
3. folders `utils` and `utils_multiClass` are the functional codes, including data pre-processing, training and testing function, OSCM definition.
4. `3.2 ImageClassification.py` is the entry file to OSCM model training and testing.

Notes: the requirements of different function is in preparation.
